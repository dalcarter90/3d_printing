Summary:
I use my Legion Go as my main PC. I use it with a USB-4 dock and have it connected to multiple monitors. However, I've always wanted a second screen on my Legion Go when I need to actually work off it portably, like a mini desktop. Either when travelling or working in the living room. I wanted the 2nd screen to be larger than the main one. I tested a few screens out and found this one to be the best, 10.5" and only $50. I found a model of a case https://www.printables.com/model/731894-lenovo-legion-go-protective-case and modified it with a hinge mechanism to fit my screen. Legion Go has 2 USB-4 ports and can be charged using a 90° USB-C cable on the bottom, or regular on top. If charging using the top port, I move the monitor cable to the bottom port. I have to recline the Legion Go in order to do this.I used some spare nuts and bolts to attach the 2 pieces together.
